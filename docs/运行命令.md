# 运行命令

索引构建、混合检索与验收测评的运行方式。

## 0 前置：装依赖

```powershell
cd "E:\Code\AIProgect\travel assistant"
pip install -r requirements-rag.txt
```

数据已经就绪：`data/processed/chunks.jsonl`（10,020 个 chunk / 400.8 万字）。

## 1 选向量化方式（三选一）

### 方式 A：BGE-M3 API（推荐，符合流程文档首选）

任何 OpenAI 兼容的 `/embeddings` 服务都行（硅基流动、魔搭、阿里云百炼、自建 vLLM 等）：

```powershell
$env:RAG_EMBED_PROVIDER  = "api"
$env:RAG_EMBED_BASE_URL  = "https://api.siliconflow.cn/v1"   # 换成你自己的服务地址
$env:RAG_EMBED_API_KEY   = "sk-你的密钥"
$env:RAG_EMBED_MODEL     = "BAAI/bge-m3"
$env:RAG_EMBED_DIM       = "1024"
```

### 方式 B：本地兜底模型（不联网、不需要密钥）

```powershell
pip install sentence-transformers
$env:RAG_EMBED_PROVIDER = "local"          # 用 BAAI/bge-small-zh-v1.5，512 维
$env:RAG_EMBED_DIM      = "512"
```

### 方式 C：auto（默认）—— 先 API，失败/熔断自动切本地并标记 degraded

```powershell
$env:RAG_EMBED_PROVIDER = "auto"
```

> 注意：`RAG_EMBED_DIM` 要和实际模型一致（bge-m3=1024，bge-small-zh-v1.5=512），
> 它只参与 Manifest 记录，向量本身以模型返回为准。

## 2 建索引（一条命令）

```powershell
# 先小样本试跑，确认链路通（约 30 秒）
python scripts/build_index.py --limit 200 --rebuild

# 全量重建（10,020 个 chunk）
python scripts/build_index.py --rebuild
```

产出：

| 文件 | 内容 |
|---|---|
| `data/index/chroma/` | Chroma 本地持久化集合 travel_kb_v1 |
| `data/index/bm25.pkl` | jieba 分词 + rank_bm25 的 BM25 索引 |
| `data/index/embed_cache.sqlite` | 以 content_hash 为键的向量永久缓存 |
| `data/index/IndexManifest.json` | 索引版本清单（7.2 要求的全部字段） |

**重跑不会重复调接口**：向量按 `content_hash` 缓存，第二次构建几乎全命中缓存。

## 3 换成独立 Chroma 容器（可选，对应 PRD 5.2 的 chroma:8002）

```powershell

```

## 4 验收

```powershell
# 字段齐全 + 向量数一致 + 5 条抽样命中 + 城市/类别过滤 + 空结果分支
python scripts/verify_index.py

# 额外做「连续两次构建一致」检查（AC-007，会再跑一遍全量）
python scripts/verify_index.py --twice

# 自定义抽样查询
python scripts/verify_index.py --queries "成都必去景点" "哈尔滨冬天注意什么"
```

## 6 常见问题

| 现象 | 处理 |
|---|---|
| `缺少 RAG_EMBED_BASE_URL / RAG_EMBED_API_KEY` | 方式 A 必须设这两个；或改用 `--provider local` |
| Manifest 里 `degraded: true` | 说明走了本地兜底，检查 API 地址/密钥/额度 |
| `Collection ... does not exist` | 先跑一次 `build_index.py` |
| 想彻底重来 | 删掉 `data/index/` 目录再 `--rebuild` |
| 加了新语料 | 重跑 `run_clean.py` → `run_split.py` → `build_index.py --rebuild` |
